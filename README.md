## 📲 WhatsApp Link Setup (Bina Number Display Kiye)

Aapka phone number website par open text me nahi dikhega. Visitors seedha button par click karke aapko WhatsApp par message bhej payenge.

Open `index.html` and search for:
`YOUR_PHONE_NUMBER`

Iski jagah apna WhatsApp number country code ke sath daal dein (bina `+` ya spaces ke), jaise:
- Agar number `9876543210` hai toh: `919876543210`

Example:
`https://wa.me/919876543210?text=Hi%20Jyoti,%20I%20saw%20your%20portfolio!`
